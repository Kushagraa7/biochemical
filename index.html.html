Quick memory map — revise all tests

Ninhydrin: amino acids → purple

Molisch: all carbohydrates → purple ring

Biuret: proteins / peptide bonds → violet

Iodine: starch → blue-black

Benedict: reducing sugar + heat → green/yellow/orange/brick-red

Barfoed: monosaccharide reacts faster → red precipitate

Seliwanoff: ketose → rapid cherry-red

Bial: pentose → blue-green

Fehling: reducing sugar + heat → brick-red precipitate

Sudan III: lipid → red-orange stain

Lipid solubility: insoluble in water, soluble in non-polar solvent

Don't mix these up: Benedict and Fehling both detect reducing sugars; Barfoed distinguishes them by reaction speed. Seliwanoff = ketose; Bial = pentose.

Simulation only. Colours are illustrative. Real practical work must be instructor-supervised, especially with concentrated acids, solvents or heat.
